# Buffet-Festa-Perfeita
Este foi um projeto da aula de Análise Exploratória de Dados da faculdade de Análise e Desenvolvimento de Sistemas.

### Funcionalidades
- Calcula de acordo com quantos convidados (mínimo 50) a quantidade de alimentos que precisa para receber os convidados na festa.
